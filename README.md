# Masjid-e-Tawheed — Future Ready Website

This is a clean, modern static website designed for GitHub Pages.

## Included
- Modern responsive homepage
- Prayer-times section
- One-year-ready Jumu'ah / event structure
- Imam & Khatib photo carousel
- Automatic video rotation
- YouTube video support
- Countdown for the next major program
- Programs and services
- Contact / Google Maps / WhatsApp placeholders
- Mobile-friendly layout

## Important
The website deliberately does NOT invent real Imam names, photographs, prayer times, phone numbers, YouTube IDs, or future event dates.

Those details are stored in `script.js` and can be replaced after the Masjid committee confirms them.

## GitHub Pages
Upload these files to the ROOT of the NEW repository:
- index.html
- styles.css
- script.js
- README.md

Then set GitHub Pages:
Settings → Pages → Source: Deploy from a branch → Branch: main → Folder: /(root) → Save.

After the first successful deployment, the website will be available at the GitHub Pages address for that repository.
